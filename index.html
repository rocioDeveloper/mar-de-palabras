Mar de palabras

Cada palabra es una gota que sube y baja. GSAP las mueve una tras otra con un pequeño retraso, y ese retraso es lo que dibuja la ola. Toca una palabra para salpicar. Abajo está la explicación paso a paso, con referencias al cheatsheet de GSAP.



  

    

      
Cómo está hecho

      
Son unas 40 líneas de GSAP. Cada paso usa una idea del cheatsheet. Puedes copiar el código de cada bloque y probarlo en CodePen.

    


    

      
1Cargar GSAP

      
GSAP es una sola librería. Con una etiqueta <script> ya tienes el objeto global gsap.


<script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.5/gsap.min.js"></script>

    


    

      
2Preparar las palabras

      
GSAP anima elementos del DOM, así que cada palabra va en su propio <span class="word">. Los spans necesitan display: inline-block, porque un elemento inline no acepta transform y no se movería.


palabras.forEach(texto => {
  const span = document.createElement("span");
  span.className = "word";
  span.textContent = texto;
  fila.appendChild(span);
});

    


    

      
3El tween: la pieza básica

      
Un tween anima propiedades de un estado a otro. El cheatsheet lo resume en tres verbos:


gsap.to(".word", { y: -18 });        // desde donde está HASTA y:-18
gsap.from(".word", { opacity: 0 });  // DESDE opacity:0 hasta como está
gsap.fromTo(".word", { y: 40 }, { y: 0 }); // tú das los dos extremos

      
y es un atajo de GSAP para transform: translateY(). También usamos rotation (grados) y scale.

    


    

      
4Stagger: el retraso que hace la ola

      
Si todas las palabras subieran a la vez, el mar subiría entero como un ascensor. stagger le da a cada elemento un pequeño retraso respecto al anterior. Con grid: "auto" GSAP detecta filas y columnas, y from dice desde dónde empieza la onda.


stagger: {
  each: 0.07,       // 0.07 s entre una palabra y la siguiente
  grid: "auto",     // calcula el retraso según la distancia en la cuadrícula
  from: "start",    // "center", "edges", "end", "random" o un índice
}

      
Pruébalo: cambia «La ola nace en» arriba. Con center parece una piedra que cae al agua; con random, lluvia.

    


    

      
5repeat y yoyo: que no pare

      
repeat: -1 repite para siempre. yoyo: true hace que cada repetición vaya hacia atrás, así la palabra sube, baja, sube, baja.


const ola = gsap.to(".word", {
  y: -18,
  rotation: 4,
  duration: 1.4,
  ease: "sine.inOut",
  stagger: { each: 0.07, grid: "auto", from: "start",
             repeat: -1, yoyo: true }   // ← dentro del stagger
});

      
Fíjate en que repeat y yoyo están dentro de stagger. Así cada palabra se repite por su cuenta y la ola fluye sin cortes. Si los pones fuera, se repite el grupo entero: el tween espera a que termine la última palabra antes de volver a empezar, y se nota un salto.

    


    

      
6Ease: el carácter del movimiento

      
El ease controla cómo cambia la velocidad. sine.inOut acelera y frena suavemente, igual que una onda senoidal, por eso es el ideal para el mar. En el cheatsheet tienes la lista: power1…power4, back, elastic, bounce, circ, expo, sine, cada uno con .in, .out o .inOut.

      
Pruébalo: elige elastic.out(1, 0.4) arriba y verás un mar nervioso. none se ve mecánico, porque la velocidad no cambia nunca.

    


    

      
7Timeline: la entrada en escena

      
Una timeline es una secuencia de tweens. El parámetro de posición (el tercer argumento) decide cuándo empieza cada uno. Aquí las palabras emergen del fondo y, cuando todas han llegado, arranca la ola.


const intro = gsap.timeline({ defaults: { ease: "power3.out" } });

intro
  .from(".word", { y: 60, opacity: 0, duration: 1,
                   stagger: { each: 0.01, from: "random" } })
  .from(".sea",  { backgroundPosition: "0 -200px", duration: 1.5 }, "<")
  .add(crearOla, "-=0.3");   // la ola empieza 0.3 s antes del final

      
"<" significa «al mismo tiempo que el anterior», "-=0.3" «0.3 s antes de que termine» y "+=1" «1 s después». Están en la sección Position parameter del cheatsheet.

    


    

      
8Controlar la animación

      
Todo tween y toda timeline devuelve un objeto con métodos. Los botones de arriba solo llaman a estos:


ola.pause();          ola.play();
ola.timeScale(2);     // el doble de rápido
ola.kill();           // la destruye (para crear otra con otro ease)
intro.restart();

    


    

      
9Bonus: la salpicadura

      
Al tocar una palabra lanzamos otro tween sobre scale y color. No choca con la ola porque esa anima y y rotation, propiedades distintas.


palabra.addEventListener("click", () => {
  gsap.fromTo(palabra, { scale: 1 },
    { scale: 1.7, color: "#ff8a6b", duration: 0.25,
      yoyo: true, repeat: 1, ease: "power2.out" });
});

    


    

      
→Ideas para seguir practicando

      
Usa tus propias palabras o una frase de un poema. Añade un segundo tween con x para que las filas también deriven de lado. Prueba stagger.axis: "x" para que la ola viaje solo en horizontal. Cuando te sientas cómoda, mira ScrollTrigger en el cheatsheet para que la marea suba al hacer scroll.
